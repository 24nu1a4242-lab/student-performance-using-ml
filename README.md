#  Student Performance Prediction Using Machine Learning

##  Project Overview
This project predicts a student’s exam score based on:
- Number of study hours
- Attendance percentage

A Linear Regression machine learning model is used to perform the prediction.

##  Technologies Used
- Python
- Pandas
- Scikit-learn

##  Project Structure
student-performance-ml/<br>
├── data.csv<br>
├── student_performance.py<br>
├── README.md<br>
├── requirements.txt<br>

##  How to Run
1. Install required libraries  
   `python -m pip install -r requirements.txt`

2. Run the program  
   `python student_performance.py`

3. Enter study hours and attendance percentage when prompted.

##  Machine Learning Model
- Linear Regression
- Train-Test Split method
- Mean Squared Error (MSE) for evaluation

##  Sample Prediction
Input:
- Study Hours: 6
- Attendance: 80

Output:
- Predicted Score: ~76.13
